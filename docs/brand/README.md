## Current Direction

Robinson PrintWorks should feel modern, engineered, premium, reliable, clean, technical, approachable, creative, confident, and functional.

Preferred palette:

- Deep Midnight Navy `#061B33`
- Satin Royal Navy `#073B78`
- Electric Cyan `#22D3EE`
- Precision Cyan `#0891B2`
- Soft White `#F8FAFC`
- Cool Gray `#94A3B8`
- Graphite `#111827`

Use cyan as precision detailing, not decoration.

## Current Priority

Evolve the existing one-page site rather than replacing it. Keep the direct local-service clarity, but reduce neon/magenta styling and build a more premium navy/cyan engineering language that can extend into product photography, packaging, social templates, and 3D printed goods.
