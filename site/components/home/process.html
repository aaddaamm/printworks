How it works

Start with the problem. I’ll check whether it is printable, then we can work out material, timing, and price.

  1. Tell me what you need Describe the problem, or send a photo, broken part, sketch, or reference. Files are welcome but never expected. If a part needs an in-person fit check, request a site visit.
  2. Get clear next steps I’ll confirm material, timing, pickup or shipping, and cost.
  3. Approve the print Once approved, I print, inspect, and package it.
